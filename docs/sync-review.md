# Sync conflict review — 1 October 2026

The shared Jellyfin/Trakt comparison previously treated metadata runtime differences, small provider rounding differences, and cleared completion resume markers as personal conflicts. Initial empty destinations also conflicted with meaningful Coast state. Conflict flags could survive convergence or successful delivery. Trakt collection lookups stopped after the first movie page. Imported episode completions inherited the manual episode-order acknowledgement requirement.

The comparison now ignores runtime-only differences, tolerates up to one second between two positive resume positions, and distinguishes zero from newly started progress. A completed Coast title at the end of its runtime has no active resume marker for synchronization; its concrete progress and history remain intact. Empty initial destinations do not compete with personal state. Matching observations clear obsolete flags, and delivery acknowledgement clears a flag only when the delivered value still matches local state. List acknowledgement uses the same user serialization and convergence rule. Trakt collection lookups traverse all pages. Actual imported watches can be recorded out of order while manual order acknowledgements and destructive-import review remain.

Existing records have a separate repair operation. It clears only converged/initial-empty provider flags, and accepts only Jellyfin/Trakt watch imports held by the exact obsolete episode-order warning. Original evidence and dates remain, repair is retry-safe, and existing export preferences govern queued delivery. It does not run automatically when the Pending page is read.

The read-only dev preview identified 88 repairable provider flags (74 progress, 12 history, 2 favourite), 21 held imported watches, and 1 remaining provider conflict. After explicit user approval, the repair cleared the 67 flags still present and accepted all 21 held watches. Verification found zero remaining provider flags, all 21 original evidence rows retained, and 21 applied review events with matching original dates, date certainty and rewatch state. Counts changed between the read-only preview and repair as normal sync continued.

Validation covers completed/reset resume equivalence, zero-to-positive progress, metadata and provider precision, convergence, genuine remote removals, manual episode-order warnings, imported history retries, original dates/evidence, multi-page Trakt collection reads, account switching, projection uncertainty and import opt-outs. Live provider acceptance is separate from the local HTTP and database fixtures.
