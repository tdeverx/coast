# Audit follow-up: retention, accessibility, playback, provider parity and observability

Product QOL and public API design are excluded. Existing visual design is preserved. This report supplements the immediate audit repairs; it does not claim complete live-provider acceptance.

## Retention and recovery

The existing maintenance tick checks transient retention hourly. PostgreSQL advisory locking prevents overlapping cleanup; each operation handles at most 500 records (full batches are revisited on the next minute tick) and skips records already locked for redemption/approval. Expiry indexes keep routine cleanup bounded by eligible records.

| Record | Policy |
| --- | --- |
| Login sessions | Remove after expiry |
| Unapproved projection previews | Remove after one day (approval already expires after one hour) |
| Unused invite codes | Remove 30 days after expiry/revocation; retain redeemed codes |
| Synced rooms | End at the existing 24-hour maximum; remove seven days after ending, including transient participant membership |
| Database diagnostics | Seven days; file diagnostics already have bounded seven-day rotation |
| Completed/cancelled/failed outbox jobs | Retain: scheduling evidence, account provenance and cleanup intent are durable |
| History, music batches/listens, playback evidence, social deliveries, sync baselines, approved projection previews and attribution | Retain; never included in transient cleanup |

Expired check-ins no longer keep Trakt on its active polling cadence. No new scheduler is introduced.

`scripts/test-recovery.ts` creates two disposable databases, migrates the first, adds an encrypted fixture connection and queued action, takes a PostgreSQL custom-format logical dump, restores the second, copies the fixture secrets directory, and verifies decryption in a fresh process. A replacement key must fail. Both databases and all fixture files are removed afterwards. It never backs up or mutates the configured application database.

Run `TEST_DATABASE_URL=… bun run test:recovery` with installed matching PostgreSQL tools. For the local Apple Container fixture use `COAST_TEST_PG_CONTAINER=coast-new-test-db` and, if necessary, `COAST_TEST_CONTAINER_TOOL=/opt/homebrew/bin/container`. PostgreSQL 17.11 logical dump/restore was exercised successfully. This verifies the database/key restoration contract; a stopped bundled-volume filesystem restore still needs a deployment-environment drill.

## Accessibility and responsive interaction

Context menus restore focus to a connected opener, falling back to their trigger if the original node has been removed. Material sliders and player volume announce units instead of raw numbers. Existing native dialog behavior, typography, colors, glass and layout are retained.

In-app browser checks verified menu ArrowDown navigation and Escape focus restoration; dialog Tab navigation and Escape; keyboard changes to material sliders (`6%`) and playback seeking (`30:01 elapsed, 1:19:59 remaining`); mobile materials/shelf layout without document overflow. The browser's effective mobile viewport was 433px despite a requested 390px override. Native accessibility-tree observations are not a full screen-reader certification or an automated contrast audit.

## Playback lifecycle

Repeated stream errors no longer reset the exhaustion timeout. Playback continues while buffered content is usable or the user has intentionally paused. Exhausted, stalled playback still reports failure after eight seconds. Tests exercise the player's actual handlers using a controlled media clock.

Synced-room responses are checked against a lifecycle generation before being accepted. A late heartbeat or host command cannot resurrect a room after leaving; source-change responses are similarly checked. A transient room-read failure retains the saved room identifier for recovery. Authoritative authentication/access/not-found responses clear it. Existing group-disconnection pause policy and audio/video navigation behavior remain intact.

Existing fixtures cover actual-play accounting, audio counts, onboarding completion, room privacy, compatible editions, source permissions, buffering policy and queue gaps. This pass provides deterministic failure evidence rather than claiming live streamed audio/video outage acceptance.

## Provider parity

The implemented capability matrix remains authoritative: Jellyfin screen/music playback and tracking, Trakt screen tracking/lists/scrobbling, Seerr screen requests, TMDB screen metadata and IGDB game metadata. Unsupported categories are skipped, never treated as sync conflicts. Trakt export now checks the actual work category, even if a stray screen-provider mapping exists. Games still require an availability-capable source to establish installation; IGDB metadata does not make a game available.

Read-only live checks verified pinned Jellyfin server identity and enabled user policy for all four connected development accounts. No Trakt account is connected, so live reconnect/account-switch/scrobble acceptance remains unverified. Existing projection, reconciliation, Trakt lists/season exports, social live delivery and account-generation fixtures were rerun. No live provider writes were performed.

## Observability

Failures persist a closed code, remediation category and retryability alongside the safe human explanation. Authentication, permissions, missing endpoints/items, rate limits, outages, invalid provider data and canonical identity conflicts remain distinct. Successful delivery clears stale failure evidence. Jobs choose their existing remediation links from these fields rather than message wording; manual retry remains available after addressing the cause. Identity conflicts stop automatic retrying.

Diagnostics admit only controlled failure codes, random account-generation identifiers and numeric retention counts. Arbitrary provider bodies, tokens and private exception text remain excluded. Existing freshness/countdown/outcome reporting and correlation IDs are reused. Internal API validation and temporary service errors now include stable codes; no public API surface was added.
