# Subtitles and player controls

Base application commit `f6e99fc`.

Opening the root media or player menu makes no subtitle discovery call. Opening the subtitle branch on a media card loads only its selected Jellyfin file. The player uses the tracks it already holds. The language list performs no remote search until the user explicitly opens a language. One active search belongs to the exact viewer, scope and language and closes through the existing menu resource cancellation path. Reopening a settled language under the same scope reuses its results. Search caps returned results at 80 and shows five in the flyout.

Search reads can retry once for transient failures. Request cancellation covers the database and provider reads for options and search. Downloads run once per active video on this process, coalesce repeat requests for the same ticket, and confirm the new track with at most five follow-up reads before selecting it. Subtitle search tokens travel in JSON bodies and bind to the current Jellyfin account and exact video identity. Download confirmation tests cover old and ambiguous tracks. The staged card selection holds at most 32 titles in the current tab. Caption rendering uses cue events on the selected browser track and a viewport layer outside the crop geometry.

Quality metadata is derived from the existing playback negotiation and availability row. The mounted player pauses on a black surface during video replacement. The old server session remains current until successful negotiation and a transaction verifies it is still the owner's active session. Handoff bypasses saved-progress lookups and same-source quality changes reuse the companion crop. Coast rejects bitrate choices above policy at preparation. Refresh writes one tab-local snapshot at page hide and checks the existing owned session and provider account before restoration. Music retains its cumulative listening time across refresh. The server still bounds newly accepted listening time by elapsed playback. Parties retain their existing restoration path.

Both trailers and normal video preparation use the Coast companion for crop metadata. Trailer requests begin during the artwork phase. Video preparation reads preferences once and fetches the crop alongside the playback metadata outside the session transaction. The player and hero use the companion result directly. If Jellyfin omits the source dimensions, the plugin rectangle can be normalized after browser metadata arrives. Trailers apply the valid crop immediately and ordinary playback defaults to full-frame fit.

Replacing a stream for the same viewing retains the first session's identity for completion in Coast and Trakt. Each Jellyfin stream keeps its own session ID and delivery lifecycle. The additive migration leaves existing session identities intact and requires no backfill.

Local checks exercised HTTP subtitle options and search for a real movie and episode on a restored Coast database. The movie returned results from its configured OpenSubtitles plugin. The UI preview exercised fixture selection, checkmarks and advanced search. Playback negotiation accepted a lowered quality preset, retained a saved position with no known runtime, and rejected an out-of-limit bitrate. Real subtitle download and full codec playback across device families require separate provider verification.
