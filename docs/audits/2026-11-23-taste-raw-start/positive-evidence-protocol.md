# Counterexamples to a public red forecast

Retain the exact creative-team correction as the personal baseline. Only reconsider the additional public-reception branch. Preserve the original 870 whole-title forecasts, the earlier 382 rating-day forecasts, the 23 November public vote snapshot and the score below 50 boundary. Classify 2½ stars and below, 3 stars, 3½ stars, 4 stars and above, and five-star favourites separately. Compare the identities of recovered dislikes as well as the count.

The two known film errors motivated these comparisons. The films and their ratings must remain hidden from their own predictions. Experiments on the same viewer and titles are exploratory, including when a rule reproduces the desired outcome.

- Test whether the original genre/tag comparisons that voted for a downward public adjustment contain any independent title this viewer actually disliked. Use the same twelve comparisons. For boundary ties, also retain all families tied at the cutoff and inspect how conclusions depend on the tie. A two-family control tests dependence on one observation.
- For titles with a below-neutral public reception, compare the most similar independently disliked work to the most similar work the viewer personally liked despite its reception. Use the existing genre/tag similarity, favour caution on ties and check the stricter version that requires an actual dislike to justify the extra red. Test both four-plus and above-neutral personal ratings as counterexamples.
- A separate control estimates how much the viewer tends to disagree with below-neutral public ratings. Use the twelve nearest distinct rated franchises on that side of neutral and the weighted median difference between personal utility and vote-adjusted public utility. Use the same genre/tag and vote-count weights. Without two independent contrasts, retain the personal prediction. Apply the previous public red only if the adjusted estimate still falls below 50. Also inspect the boundary corresponding to a clear dislike (2½ stars). Compare against simply requiring a real disliked neighbour. This guards against a small relative disagreement among mostly well-liked works authorising a large drop in absolute score.
- Check a separate franchise veto using a positive rating on another canonical title. For full-history fits, such ratings can postdate the held title. On earlier-day tests permit ratings only from strictly earlier days. Separate evidence from a sequel rated in the same import batch from evidence that would already have been available.

Donors must be of the same medium. Content-neighbour guards exclude the target's entire franchise and all ratings from the held day or later on the dated replay. The franchise veto is the one intentional use of other family members. Keep the existing unaltered score for a title when a proposed public downgrade is vetoed.
